# Hospitais Habilitados

## Estrutura da pasta

```
Hospitais Habilitados/
├── hospitais-habilitados-em-oncologia-abril-2025.xlsx
├── hospitais-habilitados-em-reconstrucao-mamaria.xlsx
└── tratamento-sincronico.xlsx
```

Os três arquivos são planilhas baixadas diretamente de fontes públicas do Ministério da Saúde/INCA, sem processamento adicional.

## O que esta pasta faz

Reúne, em nível nacional, a relação de hospitais habilitados pelo Ministério da Saúde para oncologia, reconstrução mamária pós-mastectomia e tratamento sincrônico em oncologia.
