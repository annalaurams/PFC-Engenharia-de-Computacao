# Municípios

## Estrutura da pasta

```
Municípios/
└── Relacao-de-municipios-por-vinculacao-administrativa-090.xlsx
```

O arquivo é uma planilha baixada diretamente da Secretaria de Estado de Saúde de Minas Gerais, sem processamento adicional.

## O que esta pasta faz

Fornece a base de referência territorial dos municípios de Minas Gerais, usada para associar cada município à sua Unidade Regional de Saúde (URS).
