# Seleção e Transformação - Mortalidade

## Estrutura da pasta

```
Mortalidade/
├── mortalidade_tratamento.ipynb        # notebook de tratamento
└── tabela_mortalidade_faixa_etaria.csv # mortes por município, ano e faixa etária
```

## O que esta pasta faz

Consolida os CSVs de mortalidade por câncer de mama, organizados por regional/município (extraídos em `Limpeza e Integração/Mortalidade/Cidades Atendidas por Cada Regional`), em uma única tabela com uma linha por município e colunas `<ano>_<faixa>` e `<ano>_TOTAL`.
