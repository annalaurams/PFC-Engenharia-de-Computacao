# Seleção e Transformação - Mamografias

## Estrutura da pasta

```
Mamografias/
├── mamografia_tratamento.ipynb                # notebook de tratamento
└── tabela_mamografias_por_faixa_etária.csv    # exames de mamografia por município, ano e faixa etária
```

## O que esta pasta faz

Consolida os CSVs anuais de exames de mamografia (extraídos em `Limpeza e Integração/Mamografia`) em uma única tabela por município, com o código IBGE e as faixas etárias padronizadas do projeto.
