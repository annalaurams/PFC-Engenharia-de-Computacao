# Resultados Parciais - Análises Exploratória dos Dados

## 📓 Estrutura 

```
Resultados/
├── casos.ipynb                      # Análise de incidência de casos por dimensão
├── mamografia.ipynb                 # Análise de mamografia e rastreamento
├── mortalidade.ipynb                # Análise de mortalidade e taxas
├── hospitais_habilitados.ipynb       # Distribuição e cobertura de hospitais
├── municípios.ipynb                 # Análise territorial e regional
└── README.md
```

### Descrição dos notebooks

| Notebook | Foco | Dados principais | Principais achados |
|----------|------|-----------------|-------------------|
| **casos.ipynb** | Incidência por ano, escolaridade, faixa etária, raça-cor | Tabela de incidência | Concentração na faixa 50-59 anos; crescimento a partir dos anos 2000 |
| **mamografia.ipynb** | Cobertura, tendência temporal | Tabela de mamografia | Queda em 2020; desproporção na faixa 70+ |
| **mortalidade.ipynb** | Taxas, distribuição por faixa etária | Tabela de mortalidade | 70+ concentra 28,67% dos óbitos |
| **hospitais_habilitados.ipynb** | Distribuição geográfica | Tabela de hospitais | 97,1% dos municípios desassistidos |
| **municípios.ipynb** | Análise territorial | Tabela de municípios | Concentração em BH, Uberlândia e Juiz de Fora |
